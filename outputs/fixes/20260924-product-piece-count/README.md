# 当前库存件数 · 2026-09-24

用户要求产品列表在价格右侧增加件数、价格前移，并覆盖编辑器和数据库等链路；进一步确认“件数”指当前库存，每半个月手动更新。

## 已实现

- 列表六列：选择、产品信息、价格、件数、资料、操作。编辑器增加“件数（当前库存）”和更新说明。新脚本版本 `2026092404`、样式版本 `2026092406`，刷新即可加载。
- 数据字段 `product_records.piece_count`：可空 integer，非负检查，API 与导入限制为 0～2147483647。空值为未登记、零为零库存，拒绝负数、小数和布尔值。
- 新增、编辑、详情、列表、发布快照、搜索正文、删除恢复均覆盖。旧客户端省略件数字段时保留原库存；显式 null 清空。
- 件数编辑遵守草稿/发布隔离，修改后显示待发布，发布后清除；没有再次引入金额字符串误判。旧发布快照缺此字段时按未登记兼容，不擅自把草稿库存带入发布版。
- Excel 支持保留原35列或增设唯一“件数”列，新增列可位于任意位置。旧字段、价格行、配件和备注映射保持正确。缺件数列导入为空。
- 机器人产品详情与库存追问支持“件数”“库存多少”“还有多少件”“几件”“还剩多少”，仅使用发布值。成本权限保持独立。
- 没有自动扣减、自动推算库存，也没有创建半月定时任务；由管理员更新并发布。
